# 봉화 자생식물 도감

춘양중학교 과학 수행평가(우리 지역 식물 도감 제작하기)를 위한 학생용 웹 도감입니다.
봉화의 산과 계곡에서 조사·기록된 자생식물 40종을 계절, 사는 곳, 꽃 색, 잎 모양으로 찾아볼 수 있습니다.

- 변준기 외 (2016). 국립백두대간수목원 내 산림유전자원보호구역의 관속식물상. 한국자원식물학회지 29(2): 204–224. https://doi.org/10.7732/kjpr.2016.29.2.204
